# Vision.ai — IA para Seguridad Industrial y Detección de EPP 🛡️👁️

> **Vision** es una plataforma SaaS de Visión Computacional e Inteligencia Artificial que analiza feeds de cámaras de seguridad en tiempo real para verificar el cumplimiento del Equipo de Protección Personal (EPP) reglamentario en operaciones industriales.

---

## 🚀 Características Principales

- **Consola de Monitoreo CCTV en Tiempo Real:** Simulación de feeds de video IP (RTSP/ONVIF) con HUD de IA, *bounding boxes* de detección (+99% precisión) y cambio entre sectores de planta.
- **Detección Granular de EPP:** Cascos de seguridad, chalecos reflectivos, protección ocular, arneses de altura y calzado de trabajo.
- **Simulador de Infracciones:** Alternancia interactiva entre estados conformes y alertas críticas instantáneas ante operarios desprotegidos.
- **Soporte Light & Dark Mode:** Paleta corporativa `slate/emerald` con persistencia en `localStorage` y detección de preferencias del sistema.
- **Enfoque B2B para Higiene & Seguridad:** Métricas operacionales, alineación a normativas OSHA / ISO 45001 y modal para solicitud de prueba piloto.

---

## 🛠️ Stack Tecnológico

- **Framework:** [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Estilos:** [Tailwind CSS](https://tailwindcss.com/) con modo oscuro por clase
- **Animaciones:** [Framer Motion](https://www.framer.com/motion/)
- **Iconografía:** [Lucide React](https://lucide.dev/)
- **Tipografía:** Google Fonts Inter + JetBrains Mono

## 📦 Instalación y Uso Local

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/Gonzalez-Gaston/VISION.IA.git
   cd VISION.IA
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar servidor de desarrollo:**
   ```bash
   npm run dev
   ```

4. **Compilar para producción:**
   ```bash
   npm run build
   ```
